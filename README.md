# <img src="https://lemonpop.es" width="40" height="40" valign="middle"> LemonPop App

> **LemonPop** es una aplicación de música moderna, ligera y minimalista para Windows, diseñada para descubrir nuevos sonidos, canciones y artistas emergentes en España.

---

## 🚀 Características principales

* 🎵 **Descubre música nueva:** Explora canciones y artistas independientes que se convertirán en tus próximos favoritos.
* 🎧 **Reproductor minimalista:** Diseñado para ofrecer una experiencia cómoda, rápida y limpia en Windows.
* 🎶 **Playlists seleccionadas:** Accede a listas de reproducción exclusivas de pop, indie, rock y nuevos sonidos.
* ⭐ **Artistas emergentes:** Tu espacio definitivo para conocer grupos musicales que merecen ser escuchados.
* 🔒 **100% Seguro y Privado:** Sin registros, sin recopilación de datos personales y sin rastreadores invasivos.

---

## 📦 Instalación

Puedes instalar LemonPop en tu ordenador de dos formas muy sencillas:

### Opción 1: A través del Administrador de paquetes de Windows (WinGet)
Abre tu consola de comandos (`cmd` o `PowerShell`) y ejecuta el siguiente comando oficial:

```bash
winget install LemonPop
```

### Opción 2: Descarga directa del instalador
Si lo prefieres, puedes descargar directamente el instalador clásico desde la web oficial de descargas:

👉 [**Descargar LemonPop para Windows (.exe)**](https://lemonpop.es/descargas/lemonpop-setup.exe)
